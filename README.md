Penjelasan Kode Program
1. Tuple daftar buku dan List kosong
   
   Pertama memasukkan perintah untuk daftar buku yang berisi 5 judul buku dan dilanjutkan dengan list kosong untuk peminjaman. Setelah itu menambahkan perintah untuk menampilkan buku yang ada.
2. Perulangan untuk Meminjam buku
   
   Memasukkan perintah perulangan untuk meminjam buku sesuai dengan yang ada pada daftar buku dan akan berhenti saat user mengetik 'selesai', kemudian menambahkan perintah untuk menampilkan buku yang telah dipinjam.
3. Penghapusan di List dan daftar seluruh buku yang dipinjam
   
   Memasukkan perintah input untuk menghapus buku dengan jawaban ya/ tidak. Dimana jika memilih 'ya' akan lanjut ke perintah berikutnya untuk memasukkan judul buku yang ingin dihapus. Jika 'tidak', maka tidak ada perintah penghapusan. Setelah itu menambahkan perintah untuk menampilkan daftar buku yang sudah dipinjam.
